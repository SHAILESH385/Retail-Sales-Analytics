# 📊 Retail Sales Analytics Dashboard

## Project Overview

This project analyzes retail sales data using Python, SQL Server, and Power BI to generate business insights and build an interactive dashboard.

---

## Tools Used

- Python
- Pandas
- NumPy
- SQL Server
- Power BI
- DAX

---

## Project Workflow

Raw Dataset
↓

Python Data Cleaning

↓

SQL Server Analysis

↓

Power BI Dashboard

---

## Dashboard Features

- Total Sales KPI
- Total Profit KPI
- Total Orders KPI
- Total Customers KPI
- Profit Margin
- Monthly Sales Trend
- Sales by Region
- Sales by Category
- Top 10 Customers
- Interactive Filters

---

## Business Insights

- West Region generated the highest sales.
- Technology category generated the highest revenue.
- Total Sales: ₹2.30M
- Total Profit: ₹286.40K
- Profit Margin: 12.5%
